Install Z on Windows

Windows apps must be compiled on Windows, so the cleanest way is to let your project's GitHub build it for you — your code is already on GitHub from setting up the relay, and the build runs there automatically on every push. You just download the result and run it. No coding tools needed.

source GitHub Actions tools needed none your relay z-relay.onrender.com time ~10 min

Get the app from your build

  1. 1

    Open your repo's Actions tab

    Go to GitHub, open your z-messenger repository, and click the Actions tab at the top. You'll see a workflow called build.

    If you see a green ✓ run Great — click it and skip to step 3. If there's no run, or it's red ✗ Click build in the left sidebar → Run workflow → Run workflow, and wait a few minutes.
  2. 2

    Wait for the Windows build to finish

    Open the running/most-recent build run. It builds Android, Linux, Windows and macOS in parallel — the Windows build job takes about 5–8 minutes. Wait until the run shows a green check (or at least the Windows job does).

  3. 3

    Download the Windows build

    On the run's summary page, scroll to the bottom to the Artifacts section and download z-windows-x64. It saves as z-windows-x64.zip.

  4. 4

    Unzip and run

    Right-click z-windows-x64.zip → Extract All. Open the extracted folder and double-click zapp.exe.

    Keep the files together zapp.exe needs the .dll files and the data folder sitting next to it — run it from inside the extracted folder, don't move the exe out on its own.
    See a zip inside the zip? Older builds nested it — if the folder contains another z-windows-x64.zip, extract that one too, then run zapp.exe. (I've updated the build so new ones are a single unzip.)
  5. 5

    Get past the "unknown publisher" warning

    The app isn't code-signed yet, so Windows shows a blue “Windows protected your PC” screen the first time. Click More info → Run anyway. (This is expected for an unsigned app; signing is a later step that removes it.)

  6. 6

    Connect it to your relay

    On the first screen, pick a display name and paste your relay address:

    ▸
    wss://z-relay.onrender.com  — your live relay.

    Tap Test connection (green ✓), then Create my identity. To message someone, both of you point at this same relay and swap contact codes.

!
Antivirus note. An unsigned new app can occasionally get flagged by third-party antivirus. It's a false positive (the code is yours, built from your repo) — allow it, or sign the build later to avoid it entirely.

Prefer to build it on your own PC?

Show the local build steps

Only if you'd rather not use GitHub. Install Flutter (stable) and Visual Studio 2022 with the “Desktop development with C++” workload. Then, from the unzipped project:

cd app flutter pub get flutter build windows --release

Your app is at app\build\windows\x64\runner\Release\zapp.exe — keep the whole Release folder together and run the exe from inside it.

If something's off

No “build” workflow in Actions. Make sure Actions is enabled (repo Settings → Actions → General → Allow all actions), then push any change or use Run workflow.

The run failed on a job. You only need the Windows build job's artifact — if another platform's job failed, the Windows one may still have produced its download. Open the run and check the Artifacts section.

App says “offline”. Confirm the address is exactly wss://z-relay.onrender.com and open the health page — it should say {"ok":true,…}.
